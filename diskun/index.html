Every bonus for Diskun

Earn all 249 special bonuses in Super Smash Bros. Melee at least once and the Diskun trophy is yours. Tick them off as you go. In the game, Data → Special Bonus shows the ones you already have.

Tick them from your save

Pick or drop your Melee save from Dolphin and every bonus it has gets ticked. The file is read right here on the page and never uploaded.

Where is my save?
  • Dolphin's user folder (usually Documents\Dolphin Emulator, or Dolphin's own User folder in portable builds like Slippi), then GC\USA\Card A. The file is 01-GALE-SuperSmashBros0110290334.gci. Use EUR or JAP for other regions.
  • If your card is one big file instead, pick GC\MemoryCardA.USA.raw. The Melee save is found inside it.
  • Anywhere else: in Dolphin, open Tools → Memory Card Manager and export the Melee save as a .gci.
  • The game writes the save when you leave a match or menu, so finish what you're doing before you load the file.
